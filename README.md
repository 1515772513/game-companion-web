# game-companion-web
游戏陪玩-管理端
管理端（PC 后台）Vue3 + Vite + Element Plus
这是为陪玩小程序平台量身打造的 PC 管理后台，基于 Vue3 + Vite + Element Plus 开发，采用前后端分离架构，对接 .NET 8 WebAPI 后端。
项目介绍
面向运营人员、管理员使用
支持用户管理、陪玩师审核、订单管理、提现审核、数据统计、系统配置
界面美观、操作简单、加载速度快
适配 PC 端，支持权限控制、路由守卫、请求拦截
技术栈
框架：Vue 3 (Composition API)
构建工具：Vite
UI 组件库：Element Plus
网络请求：Axios
路由：Vue Router 4
状态管理：Pinia
代码规范：ESLint
对接后端：.NET 8 WebAPI + MySQL + websocket
